## Overview

1/5 스케일 전동 차량을 자율주행 플랫폼으로 구축하고 있다. 이전 프로젝트에서는 이미 구성된 차량이나 시뮬레이터 위에서 알고리즘을 주로 개발했지만, 이번에는 배터리·motor driver·STM32·조향 feedback·GNSS 등 차량 하드웨어 연결부터 직접 시작하였다.

현재 듀얼 RTK GNSS 기반 위치 및 heading 추정과 waypoint 주행이 가능하며, 저속에서는 경로를 안정적으로 추종하지만 속도가 높아지면 경로 이탈이 발생해 제어를 조정하고 있다.

### Hardware

- 배터리·전원 배선

- 조향 feedback
- 듀얼 RTK GNSS 설치

- 실제 대회장 waypoint 취득
- Spline 기반 경로 생성
- waypoint 주행 시험

- Mission Manager
- YOLO 학습용 데이터 수집

## System Development

### Hardware Integration

배터리와 전원, 구동·조향 motor driver, STM32, 조향 feedback sensor를 직접 연결하였다. 소프트웨어 명령이 STM32와 motor driver를 거쳐 실제 모터를 구동하고, 조향 feedback이 다시 들어오는 구조를 확인하였다.

### Dual RTK GNSS

차량의 앞·뒤에 RTK GNSS를 하나씩 설치하고 두 위치의 차이로 heading을 계산해 waypoint 주행에 사용하고 있다.

### Waypoint Acquisition & Path Generation

실제 대회장에서 GNSS waypoint를 직접 취득하고, 점들을 그대로 선분으로 연결했을 때 생기는 꺾임을 줄이기 위해 전산모델링 수업에서 배운 Spline 보간을 적용해 기준 경로를 생성하였다.

### Mission Manager

운전면허시험 코스에서 각 미션이 시작되고 끝나는 위치를 waypoint와 연계하였다. 차량이 특정 미션 구간에 진입하면 해당 기능을 활성화하고 종료 지점을 지나면 다음 주행 상태로 넘어갈 수 있도록 Mission Manager를 구성하였다.

### YOLO Dataset

정지선·신호등 인식을 위해 실제 대회 환경의 데이터를 수집하고 YOLO를 학습하였다. 모델 학습은 완료했으며 현재 전체 미션 로직과의 통합을 진행하고 있다.

## Takeaways

이전 프로젝트에서는 이미 준비된 차량 위에서 알고리즘을 주로 다뤘지만, 이번에는 배선부터 GNSS waypoint 취득과 경로 생성, 미션 로직까지 직접 연결하고 있다. 차량 한 대가 자율주행하기 위해 소프트웨어 외에도 많은 구성 요소가 맞물려야 한다는 점을 처음 제대로 경험하고 있다.
